# Specular

This repo is the Specular Claude Code plugin (markdown skills under `skills/` plus the bash loop driver `bin/specular-ralph`). We dogfood Specular on itself.

## Linear

File Linear tickets under team **UI** (UI), project **Specular**. Leave new tickets unassigned unless told otherwise.

## Validation

No lint, typecheck, or test suite - this repo is markdown skill instructions and one bash script (`bin/specular-ralph`). `/specular:implement` should skip the validation gate.
